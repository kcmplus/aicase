## 分阶段交付

| 顺序 | 工作 | 验收重点 |
|---|---|---|
| 1 | 页面、功能、接口对照；确定新版演示与现有业务的差异 | 全部页面和用户可达功能有去向，明确适配依据 |
| 2 | 新版整体布局、首页、导航、作品/图库、教程/关于、响应式与中英文 | 手机与桌面对照截图，无主要页面遗漏 |
| 3 | 相册、AI、编辑器、预览、保存与恢复设计、账户 | 使用现有后端契约，去掉假登录、假 AI 完成 |
| 4 | 后台机型 RGB 颜色、资源管理、初始化及前台接入 | RGB 色块；没有可用颜色就跳过；重复初始化保留人工配置 |
| 5 | 单份结算、支付状态、订单列表/详情、设备扫码与网点展示 | 新单一份；真实服务端状态；历史快照保持 |
| 6 | 全站回归、隔离浏览器端到端、视觉核对及产品验收 | 所有验收项及固定检查通过才完成 |

这些是一个总任务内的实施顺序，不表示现有 harness 支持自动串行执行多个任务文件。harness 仍按产品规划 → 开发 → 独立测试 → 固定检查 → 产品复核循环；阶段进展与证据写入迁移文档，整体验收未通过就继续修复。

## 已确定的业务规则

- 相册是首页主入口；保留有效设备入口、已有订单分流和旧深链接。
- 新打印订单固定一份；历史已付多份数量与金额不改，AI 数量和计费不随之改变。
- 颜色保存为 `rgb={r,g,b}`，每个通道 0–255 整数；页面显示色块，名称仅辅助。
- 首份资料覆盖 50 款型号：44 款共 218 条颜色可供匹配初始化，6 款待确认不猜值。没有真实预览资源的初始颜色为停用草稿；没有可用颜色仍正常使用机型原有预览。
- 新版的演示订单、定时器支付和手动“已打印”由现有服务端流程替换。没有实际能力的配送、附近搜索等不得展示虚构交易成功或承诺；产品负责明确未开放提示或入口处理。
- 手机确认打印、供应商状态、退款/取消、权限和防重复规则保持；设备屏不在本次修改范围，出货不自动等于领取。

## 完成标准与运行边界

共 13 项验收：整站覆盖、视觉、设计编辑、身份与 AI、单份打印、后台颜色、初始化、颜色接入、目录与设备、结算订单、本地端到端、兼容回归、交付说明。

固定检查包含现有用户端测试、新版专用测试、相关后端业务测试、迁移一致性、后台构建和整站浏览器端到端。新增测试文件及浏览器脚本是执行时须开发的交付物，目前未创建；配置格式校验不代表这些检查已经通过。

端到端使用合成图片、临时数据库及独立端口，跑迁移后实际页面的完整本地零元模拟流程；非零渠道及供应商状态使用受控 mock。禁止真实资金、真实供应商/硬件操作、部署和推送。已有数据库和未提交工作必须保留。

用户已确认任务范围，启动脚本已准备，由用户运行。交付时提供迁移后的本地访问地址和真实验收证据；当前 4190 的参考 UI 地址不能当作已经迁移完成的证明。

## 用户启动入口

启动脚本：`scripts/run-ui-harness.sh`。脚本会自行定位项目目录，要求从包含 origin/main 的干净 codex/ 功能分支开始；开发/测试交接时自动提交本地检查点。

```sh
cd /Volumes/program/gaoyue/aicase
bash scripts/run-ui-harness.sh check
bash scripts/run-ui-harness.sh start
```

`check` 已通过配置预演，不调用模型或执行业务测试。启动、继续、状态与停止的命令转发已用临时目录及假执行器验证，尚未实际运行本次整站迁移。

保持启动终端打开；可另开终端使用以下操作（路径可直接使用绝对路径）：

```sh
bash /Volumes/program/gaoyue/aicase/scripts/run-ui-harness.sh status
bash /Volumes/program/gaoyue/aicase/scripts/run-ui-harness.sh stop
bash /Volumes/program/gaoyue/aicase/scripts/run-ui-harness.sh resume
```

以上管理操作自动定位本仓库最近一次 `storefront-v35-migration` 任务，忽略其他任务。达到限制或中断后使用 `resume`；不要再次 `start` 创建新运行来替代恢复。恢复使用冻结任务并重新验收，每次恢复获得新的运行预算。

默认每次启动/恢复最多 12 轮、8 小时，单次 agent 超时为 60 分钟。可追加 `--max-cycles`、`--max-seconds`、`--agent-timeout` 调整；轮数与总时长都为 0 时不限，遇到阻塞或错误仍会停止，不能保证最终完成。日志与状态保存在 `.codex-harness/runs/`。
