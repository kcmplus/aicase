# AI 风格生成：原型与接入方向

当前为英文优先的简约本地原型。AI 已改为 **$9.90/月，20 次/月，首次赠送 1 次**；常规打印为 **$10/次**，不包含在订阅内。没有实际收款、续费、模型调用或打印设备接入。

## 已实现

- 人像、宠物、情侣和旅行四类案例，共六组前后对照；样片均为固定素材。
- 先确认使用免费体验或订阅额度，再进入约 30 秒演示队列；失败或排队取消会返还额度。
- 免费体验与月度额度分开；先用体验，月度最多 20 次，不累计。按订阅日期重置；取消续订后当前周期仍可用。
- 订阅和任务保存在同一 IndexedDB 事务记录中，防止重复扣次。刷新恢复进度，生成完成后可应用示例结果。
- 上传路径明确说明示例结果并非用户照片的真实转换。
- 先预览与修改，再确认 $10 模拟打印订单并保存唯一二维码。
- 开印前可免费更新已确认订单，旧码失效；重新生成 AI 效果消耗 1 次。开印后锁定图案，修改需另建订单。

## 官方服务调研（2026-10-22）

| 服务 | 可用能力 | 对本项目的意义 |
| --- | --- | --- |
| [fal · FLUX Kontext Pro](https://fal.ai/models/fal-ai/flux-pro/kontext/api) | 图片与提示词输入、图像编辑；异步提交、状态查询、结果查询与 webhook | 可将风格卡映射为固定提示词，在服务端接入真实生成 |
| [Replicate · FLUX Kontext Pro](https://replicate.com/black-forest-labs/flux-kontext-pro) | 通过文字指令修改输入图像，官方展示卡通转换等用例 | 可作为另一部署渠道，需要评估延迟、失败率和输出质量 |
| [Black Forest Labs Kontext](https://bfl.ai/blog/flux-1-kontext) | 图像编辑、角色一致性和风格参考 | 符合上传照片后换风格的产品方向 |

fal 与 Replicate 模型页面查询时均列出 $0.04 / output image；这只是该型号的供应商推理单价，会变化，不包括支付、存储、重试、内容检查与打印，也不构成最终定价建议。当前样片由内置 ImageGen 制作，并非这些 API 的质量测试结果。正式选型前应以自有样本评估人像、宠物、插画、文字保留和适合打印的分辨率。

## 正式接入需要

1. 在服务端维护账号、一次性体验权益和订阅周期。验签订阅支付回调后发放 20 次额度，以任务 ID 原子预留额度并防止重复扣次；打印订单单独收款。前端状态不可证明付款或剩余额度。
2. 在服务端持有模型 API key；不能放进前端代码。用户确认后上传输入图，保存对象存储引用与不可变风格参数。
3. 用 [fal 官方队列](https://fal.ai/docs/documentation/model-apis/inference/queue)的 IN_QUEUE / IN_PROGRESS / COMPLETED 映射界面状态。只有有真实数据时显示队列位置；完成状态仍需检查失败信息。等待时长由服务端统计估算。
4. 验证 webhook，查询真实结果并保存到受控存储，再开放应用按钮。不要长期依赖供应商临时图片 URL。
5. 取消与失败需按真实生成任务状态幂等返还额度。订阅续费失败、到期和退款由支付回调驱动，不能直接沿用本地计时器或浏览器时间。
6. 跨设备打印通过服务端方案 ID 获取生产图片及裁切/机型参数；保存生产分辨率原图，控制访问、过期与重复打印。修订未开印订单时使旧码失效，并将开印与锁定设计放在同一服务端事务中。

API keys 和付款账户尚未配置；当前没有创建外部付费账户或发送任何访客上传照片。
