- 有效入口仍是 `frontend/storefront/index.html` → `simple-app.js`，新公共展示在 `v35-shell.js` / `v35-shell.css`、`v35-pages.js` / `v35-pages.css`；复用原业务服务，未引入参考版模拟订单、身份和付款脚本。
