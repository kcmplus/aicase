# AI 生图镜头避让与主体安全区

## 使用入口

后台 **机型管理 → 底图与构图 → AI 构图区域**。按普通款 / 磁吸款和模板版本分别设置：

- 绿色矩形：完整头部、脸、宠物及其他重要主体的放置范围。
- 红色矩形：镜头等遮挡区域，最多 8 个，与安全区不能重叠。
- 可拖动、缩放矩形，也可输入相对整个模板画布的百分比坐标。
- 安全区额外留白默认为 3 个画布百分点；可保存资料来源、核对备注与人工核对标记。
- 「填入遮罩建议」只修改当前草稿；保存才生效。「恢复自动建议」移除此模板的人工覆盖。

已有预览遮罩时，首次读取即自动生成建议，无须批量改写机型数据。算法在画布中央 60% 宽度寻找最长连续透明可打印区（预览遮罩 alpha ≥ 250），顶部整段作为保守避让区。不同开孔形状仍需人工核对；无有效遮罩时使用顶部 35% 避让、x=20%、y=35%、宽=60%、高=55% 的保守示意区域，不宣称来自官方尺寸。

## 生成与编辑

前台提交机型、款式和所选模板 ID。服务端只接受该机型 / 款式对应的已保存模板，库存快照过期不影响构图引用；付款与打印原有库存、模板校验保持独立。模板版本已失效则要求重新选择，不静默换成另一款式。

每次生成保存构图快照，包括模板、款式、配置版本、坐标及适配方式。重试同一请求保持原快照，不重新扣次数；修改模板或款式需新请求。配置只影响后续新生成任务，历史生成图不重排。

输出仍为 1024×1536。主体安全区先扣除留白，再映射到原图完整居中放置时的坐标，加入生成提示词。提示词要求保留完整头发、耳朵、脸及主体，必要时缩小主体、扩展背景。

应用新生成图时默认使用编辑器现有 **Blur fill**：前景完整显示，模糊背景补齐手机壳比例。旧生成记录保持原行为。若用户已切换机型、款式或模板，则要求选择原配置或重新生成，避免将旧构图误当成新机型适配结果。

这属于构图引导，模型不一定严格服从坐标；本版未增加人脸检测或自动重新生成。仍需在预览确认头部与镜头开孔关系。不将原始遮罩、客户图片写入公共素材，不更改最终打印文件尺寸、设备授权或扣库存逻辑。

## 发布与验证

需先执行数据库迁移 `0037_ai_composition_regions`，再提供新版后端与前端。迁移仅增加字段，保留历史订单、生成图与人工配置。

本地验证：区域检测与坐标换算、权限与配置校验、配置版本冲突、款式与模板匹配、库存过期、同请求幂等与扣次、前台完整图片放置。浏览器使用独立临时数据库验证后台拖动与保存，不调用付费生图或真实打印。本地验证不等于线上部署或真机校准。
