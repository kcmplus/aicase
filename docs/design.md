# AI CASE STUDIO 原型设计

依据：用户 2026-10-16 本次请求，以及引用对话中可读取的用户确认。历史助手正文不可读取，不补造商业规则。

目标：手机优先的六页高保真交易原型，邮寄与线下即时打印同等可达。所有价格、库存、时效、账户、AI、支付、任务及物流为演示，不连接外部交易服务。

视觉：奶油白底、炭黑正文、荧光黄主操作，编辑式大标题，艺术手机壳样品和细线卡片。360/390 手机、768 平板、1440 桌面及 1080×1920 设备屏幕响应式。

2026-10-16 品牌修订：用户指定融入 POPOMO Logo 与品牌色，并明确大面积底色仍为白色或米白色。以粉 #E44592 和青 #30B7B9 替换原荧光黄/橄榄色强调，保留布局及交易流程；使用参考图原版字样与“一刻相伴 · 始终有你”标语。

架构：无构建依赖的 HTML/CSS/ES modules；core.js 处理数据与规则，app.js 处理路由和交互，views.js 输出六页，styles.css 响应式。浏览器 localStorage 保存演示账户、机型、设计、订单；不收集真实凭证。

页面：首页；设计工作台（机型选择并存为默认、图库/照片上传、风格预设与美化模拟、缩放和预览）；交付（邮寄/设备）；结账（摘要、邮寄表单、模拟成功/失败）；订单（可推进打印/物流、取货码、演示取货）；设备页（设备 ID、支持、库存、换设备、邮寄备选）。

扫码链接 ?device=SH-001：读取登录账户的默认机型并校验该设备；新访客选机型后可保存到演示账户。未登录不冒充已登录。库存和支持状态独立检查。未知设备拒绝默认替代；缺货、不支持、离线均阻止现场结账并提供邮寄和其他设备。

支付时再次校验机型和库存，订单保存设计快照。支付失败不建单；重复提交不重复建单。邮寄表单必填；现场不要求收货地址。订单推进由显式演示按钮触发，刷新不回退，终态不重复执行。
