# 后台基础版：架构与权限

## 2026-10-27 提示词管理

新增 `/admin/ai-prompts` 集中管理页。风格使用已有 `AIStyle.prompt`；机型使用新增 `PhoneModel.adaptation_prompt`，迁移为 `0004_phonemodel_adaptation_prompt`。两类文本均允许留空，最多 4000 字，通过原管理详情接口 PATCH 单一字段保存，复用模型查看 / 修改权限和审计日志。审计仅记录字段名，不记录提示词正文。

页面分别按 `view_aistyle` / `view_phonemodel` 显示可访问配置，写入要求相应 `change_*` 权限。只读用户可以选中和复制完整内容。保存前可选择另一类配置预览组合文本；这只是手工测试辅助，不调用模型服务。离开编辑时提示未保存修改。内置模板仅在管理员主动填入、保存后写入数据库，不改变风格启用状态或机型打印校准状态。

公开目录对机型采用显式字段白名单，排除 `adaptation_prompt`，风格同样不公开 `prompt`。机型文字规则不能代替供应商实际壳型的开孔、出血和安全区模板；iPhone 15 Pro 模板明确标为未校准示例。初始化目录保持幂等，不覆盖已保存提示词。

## 选择

- Python：Django 5.2 LTS，使用自带的认证、密码哈希、用户/组/权限、数据库迁移。
- API：Django REST Framework，管理接口统一序列化、分页、服务端权限与会话验证。
- 管理前端：Vue 3 + Vue Router + Element Plus + Vite，独立项目，中文运营界面。
- 数据库：本地 SQLite；生产配置支持 PostgreSQL。
- 用户端：保留轻量原生 JS 编辑器，文件完整迁移，不强行重写为 Vue。

## 权限分工

| 角色 | 内容配置 | 订单 | 账号与授权 | 日志 |
|---|---|---|---|---|
| 超级管理员 | 完整管理 | 查询、客服备注 | 完整管理普通管理员与角色 | 查询 |
| 运营管理员 | 品牌、机型、图库、素材、AI 风格、套餐 CRUD | 无 | 无 | 无 |
| 客服人员 | 查看机型、设计、套餐 | 查询、客服备注 | 无 | 无 |
| 只读人员 | 查看业务配置 | 查询 | 无 | 查询 |

每个角色可按模型分配查看、新增、修改、删除。权限清单授予 auth 写权限本身不赋予授权能力，后台会额外检查超级管理员。超级管理员身份创建/撤销仅通过受控运维操作；管理界面不能停用或删除超级管理员。

## 数据接入边界

初始化数据来自当前编辑器真实素材，不创建收入或订单样例。管理配置能真实写入数据库，并通过公开目录 API 读取。价格、AI 次数、风格与案例已接入公开目录 API；机型和图案仍使用静态目录。原浏览器草稿/订单不上传，付费、订阅和 AI 仍是既有演示。

下一阶段接入用户端时，应保留旧 POP-1 的固定编号；新动态机型/方案与跨设备订单须使用服务端不可预测标识。订单设计快照必须独立保存，不随图库配置更新；支付状态仅由受验证的支付回调变更；AI 额度预留/退款需事务和幂等；打印开始需机器认证、库存锁定与一次性打印授权。不能仅将现有 localStorage 上传就认为已具备真实订单服务。
