# 创作者社区互动 1.0

更新：2026-10-21。对应用户确认：参考提供的小红书布局与互动逻辑，增加点赞、收藏、关注、评论。采用 POPOMO 白色/米白底色、品牌粉和青色，保留中文简体、美式英语及手机壳 DIY 主线。

## 页面与流程

- 发现页 `#discover`：桌面侧栏 + 搜索 + 三类内容筛选 + 瀑布流；手机为顶部入口、双列内容流。沿用整壳设计、照片、贴纸三个发布类型。
- `#discover?feed=following`：当前演示账号关注的作者所发布的内容；`feed=saved`：当前账号收藏的作品。两者继续支持类型筛选及搜索。
- 作品卡片：大图、标题、作者头像和名称、点赞及收藏数量。点击作者进入其主页；点击作品打开详情。
- 详情弹层：桌面左大图、右作者/关注/作品介绍/评论，底部固定互动和 DIY 入口；手机大图在上，内容向下浏览，底部操作可见。
- 弹层 URL 为 `#discover?post=作品ID` 或 `#creator?id=作者ID&post=作品ID`；关闭、Esc、浏览器返回恢复原内容流位置，前进可重开。直接详情链接 `#content?id=作品ID` 仍可使用。
- “复制设计并编辑”创建独立副本；照片/贴纸“加入我的设计”添加图层；来源、版本和原有交易规则保留。

## 互动规则

| 功能 | 规则 |
| --- | --- |
| 点赞 | 每账号每作品只有一个状态；再次点击取消，计数同步变化 |
| 收藏 | 每账号每作品一个状态；可取消，在“我的收藏”找回 |
| 关注 | 针对创作者账号，详情和主页状态同步；可取消 |
| 评论 | 登录演示账户后发送，去首尾空白，1–300 字符；输入按文本显示，不执行 HTML |
| 回复 | 一层回复；回复其他回复时归入同一主评论；已删除的主评论不能接受新回复 |
| 删除 | 仅可删除自己的评论/回复；主评论有其他回复时显示已删除占位，不抹去其他人的回复 |
| 登录衔接 | 访客可浏览；点击互动时打开既有演示账户入口，登录后继续该次操作；关闭账户窗口或离开原页面即取消待完成操作 |
| 下架 | 不再出现在发现、关注、收藏结果中；不能继续使用或互动；订单已有快照保留 |

评论显示稳定的演示昵称，不把邮箱显示为作者名。互动计数从零开始，统计此浏览器已保存的本机演示账号行为，不伪装成平台真实热度。评论草稿按当前账号及作品隔离，仅在当前页面会话保留。

## 数据和组件

- `dist/social-core.js`：与 DOM 无关的数据规则，保存于 `s.social.accounts[email]`（likes/saves/follows）及 `s.social.comments[contentId]`。
- `dist/social-view.js`：卡片按钮、作者关注、详情、评论及回复展示；全部用户文本转义。
- `dist/social-events.js`：弹层、路由、返回与焦点、登录衔接、评论草稿、互动控制。
- `dist/social.css`：瀑布流、侧栏、详情弹层和移动端样式。
- `dist/creator-view.js`：发现/作者主页整合；`dist/app.js`：状态保存、登录回调与路由整合。
- 旧工作台模板收藏 `s.favorites` 与社区作品收藏独立，避免更改既有交互。

状态沿用 `ai-case-studio-v1` 本机存储。没有发送互动数据的网络请求，没有真实用户登录、服务端权限、全球计数、跨设备同步、创作者通知或真实内容发布。浏览器里的模拟账号不代表生产身份验证。清除浏览器数据会丢失演示互动；当前原型不承诺并发标签页的社交状态一致性。
