# POPOMO · AI CASE STUDIO

手机优先的六页响应式高保真网站原型。所有数据和交易为演示。

支持简体中文（zh-CN）和英语（美国，en-US）。右上角可切换，偏好保存在当前浏览器；分享链接可使用 `?lang=zh-CN` 或 `?lang=en-US`。英文使用美式日期表达，时间仍为上海时区，价格仍为美元 USD。切换语言保留机型、设计内容、表单输入和订单；用户文字与地址不自动翻译。

## 运行

安装 Node.js 20+ 后，在此目录执行 `node server.mjs`，打开 http://127.0.0.1:4173 。不需要安装前端依赖。

Windows 也可以右键 `start-preview.ps1`，选择“使用 PowerShell 运行”。它会尝试使用系统或 Codex 自带的 Node.js，启动本地服务器并打开浏览器。

自动化核心、编辑器与购物车测试：`npm test`（39 项，包含创作者与美化规则）。

浏览器测试：`node tests/browser.mjs` 与 `node tests/regressions.mjs`。本机版本使用 Codex 自带 Playwright 和已安装的 Microsoft Edge；移到其他电脑时需安装 Playwright 并调整测试文件中的依赖加载路径。

验证：6 项核心规则测试、17 项浏览器流程/回归检查通过；六页在 360、390、768、1080、1440 像素宽度下未发现横向溢出。截图和检查结果在原工作目录 `test-results/`。

多语言验证：`node tests/languages.mjs`，11 项检查通过，覆盖语言记忆、用户内容与机型保留、表单错误恢复、结账与两种交付闭环，以及两种语言在五种屏幕宽度下的六页布局。

公开访问：https://ai-case-studio-53671.acus-ny-9168.chatgpt.site 。用户已授权源码上传与免登录公开发布。

POPOMO 视觉：依用户提供的品牌图采用粉色 #E44592、青色 #30B7B9、奶油白 #FEF4E8；大面积保持白色/米白色。页头、页尾和设备标识通过 SVG 视窗显示参考图中的原版 Logo。原图保存在 dist/assets/popomo-brand.jpg；品牌样式独立位于 dist/brand.css。主色仅作重点和装饰，不改变交易规则。

## 体验路线

- 首页 → 开始创作 → 选择型号、上传照片/选图案、调整风格、缩放和文字 → 交付方式 → 邮寄到家 → 填入演示地址 → 勾选确认 → 模拟支付 → 推进物流直至签收。
- 账户 → 保存默认机型 → `?device=SH-001#device` 模拟扫码 → 自动带入机型 → 库存验证 → 设计 → 现场打印 → 模拟支付 → 推进打印 → 输入取货码取货。
- SH-001：iPhone 15 缺货，Samsung S24 / 小米 14 不支持。SH-002 支持全部演示型号且有库存。SH-003 离线。未知 ID 显示不可用。可以切换其他设备或改为邮寄。
- 结账“测试支付异常”可模拟失败；不会生成订单。订单和设计保存在当前浏览器。
- `?device=SH-001&screen=kiosk#device` 为设备大屏模式；设备页也有切换按钮。

## 演示边界

无真实登录、支付、打印、物流、AI、地图定位或摄像头扫码连接。账户只在本机保存；扫码以 URL 参数/设备 ID 输入模拟；AI 采用浏览器滤镜；外观和摄像头模板为 2D 示意。图片只在浏览器处理、压缩并本地保存，不上传服务器。示例 USD 69、运费 USD 8、约 5 分钟与地址、库存均不是正式商业规则或承诺。

源代码：dist/core.js（规则）、dist/views.js（页面）、dist/app.js（交互）、dist/art.js（矢量样品）、dist/styles.css（响应式）。

28 款图案可分类、搜索、收藏和套用。工作台支持 24 款贴纸、照片图层、文字与字体/颜色、8 种印刷底色、拖动与位置滑杆、大小和旋转、图层复制/排序/删除、撤销与重做。完整设计保存在本机并写入演示订单。中文与美式英语均支持，所有价格仍使用 USD。

新增模块：catalog.js（素材与模板）、editor-model.js（图层和历史）、studio-view.js（界面）、studio-events.js（交互）、studio.css（响应式）。

参考拆解与边界见 [docs/studio-analysis.md](docs/studio-analysis.md)。新增浏览器测试：`node tests/studio.mjs`，17 项检查通过，包含五种宽度与双语下的所有编辑标签页。素材署名见 `dist/assets/stickers/README.txt`。

## 导航与可选搭配配件

左上角菜单打开侧滑导航，包含搜索、账户、语言、默认手机型号、定制与邮寄/打印入口。不展示“设计系列”；手机壳定制保持首页和菜单的主要主题。四类配件在抽屉中默认展开为一级类目，并加入顶部导航；手机端导航支持横向滑动。顶部第一行 Logo 始终居中，第二行提供导航及语言切换。不添加首页配件主推区。

四类配件：手机挂绳、手机钢化膜、MagSafe 兼容配件、表带。商品库 `#shop` 支持双语搜索、分类、详情、规格选择和演示库存检查。`#cart` 支持数量与移除；工作台“搭配配件一起邮寄（可选）”把当前机型和完整设计快照加入购物车。

配件及购物车合并订单只支持邮寄：备货与定制 → 中国发出 → 抵达目的地 → 本地配送 → 送达。`#cart-checkout` 可填写国际演示地址并合并结账；原单手机壳的邮寄和现场打印流程保持可用。运费沿用每单 USD 8 演示值，不代表真实跨境运费、税费或时效。购物车支付成功后清除已购买数量，失败保留商品；订单保存不可变的商品、规格、价格与设计快照。

配件商品图为内置 ImageGen 生成的示意图，准确提示词与文件记录见 [docs/accessory-assets.md](docs/accessory-assets.md)。壳体资料页 `#materials` 明确显示实物照片、材质和性能尚待补充。

新增 `node tests/shop-browser.mjs`：22 项浏览器检查通过，覆盖菜单焦点、搜索后语言切换、默认型号保存、图案替换撤销、库存、合并金额、支付失败/成功、物流阶段，以及双语五种宽度布局。此版本共 87 项自动化检查通过（20 项模型测试 + 67 项浏览器检查）。

## 消费者营销交互（2026-10-17）

新增 `#offers` 活动领券与 `#offers?tab=wallet` 本机账户优惠券；首页、顶部、菜单、设备页和账户提供入口。两类结账支持选券抵扣，失败不核销、成功保存优惠快照；配件合并订单仍全部邮寄。活动链接仅分享公开活动信息，原扫码来源在更换设备或改邮寄后保留。
